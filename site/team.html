threat-sweep

Orchestrator prompt. Passes the history-based exclude list to every scout, dispatches them in parallel, hands off to the gatekeeper, and writes latest.json and history.json. The only component that writes files.

How a run flows

  1. Orchestrator reads history.json and builds the exclude set.
  2. Six scouts run in parallel on their own beats and return JSON only.
  3. Gatekeeper merges, dedupes, re-scores, and ranks.
  4. Orchestrator re-checks against history and publishes the survivors.
